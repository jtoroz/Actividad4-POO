## Contenido

Codificación en Python, con interfaz gráfica de usuario en Tkinter, de los siguientes ejercicios del libro *Ejercicios de programación orientada a objetos con Java y UML* de Leonardo Bermón Angarita:

- Ejercicio 6.4 (página 400) - Excepciones
- Ejercicio 6.5 (página 406) - Lanzamiento de excepciones
- Ejercicio 6.6 (página 412) - Catchs múltiples
- Ejercicio 6.7 (página 418) - Validación de campos
- Ejercicio 6.8 (página 427) - Lectura de archivos

## Ejecución

Los programas abren ventanas de escritorio, por lo que deben ejecutarse localmente:

```
python actividad4_ej64_excepciones.py
python actividad4_ej65_vendedor.py
python actividad4_ej66_calculos.py
python actividad4_ej67_equipo.py
python actividad4_ej68_archivo.py
```

En Google Colab no funcionan, porque es un entorno sin interfaz gráfica.

El ejercicio 6.8 lee el archivo `prueba.txt`, que debe estar en la misma carpeta del programa.
